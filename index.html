    IMPLEMENTASI 5 KOMPONEN WAJIB STRUKTUR DATA

    1. Array In-Memory (js/data.js & js/repository.js)

    Menyimpan 10 elemen katalog produk di memori utama dengan pemisahan konstanta data master (`MASTER_PRODUCTS_DATA`) dan kloning objek imutabel.

    2. Struct / Class Entitas (js/struct.js)

    Representasi struktur data heterogen melalui class Product (ID, nama, kategori, harga, rating, stok, alamat memori) serta class CartNode.

    3. Pointer / Singly Linked List (js/struct.js)

    Keranjang belanja dikelola menggunakan rantai pointer objek nyata di Heap Memory (this.head dan referensi this.next) untuk operasi tambah, kurang kuantitas, hapus simpul, dan clear().

    4. Sorting + Step Log (js/algorithms.js)

    Menggunakan algoritma murni Insertion Sort dan Selection Sort berbasis Generator (function*) lengkap dengan penghitungan metrik perbandingan & pergeseran/pertukaran.

    5. Searching + Step Log (js/algorithms.js)

    Menggunakan algoritma murni Linear Search dan Binary Search (dengan validasi keterurutan Array) berbasis Generator (function*).
